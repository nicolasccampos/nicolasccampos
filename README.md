## 📌 Sobre mim

Sou estudante de Ciência da Computação na FECAP e busco estágio em desenvolvimento back-end com Java. Meu foco atual de estudo é Spring Boot, APIs REST e persistência de dados. Minha experiência prática inclui projetos acadêmicos em equipe e o desenvolvimento do Studie and Grow, um fluxo automatizado para publicar minhas anotações.

## 🌱 Estudando agora

- Spring Boot: APIs REST, camadas de serviço e persistência.
- JavaScript: funções, escopo e closures.
- Java: orientação a objetos e modelagem de classes

## 🚀 Projetos

### 📚 Studie and Grow: caderno de estudos automatizado

Pipeline que sincroniza anotações do Notion via API, converte o conteúdo para Markdown, gera um site com VitePress e publica no GitHub Pages com GitHub Actions.

**Tecnologias:** `Node.js` `Notion API` `VitePress` `GitHub Actions` `GitHub Pages`

➡️ [Repositório](https://github.com/nicolasccampos/studie-and-grow) · [Site publicado](https://nicolasccampos.github.io/studie-and-grow/)

### 🕹️ Axis Defense: projeto interdisciplinar (1º semestre · FECAP)

Survival shooter 3D para desktop, desenvolvido por uma equipe de quatro pessoas com Unity e C#.

Atuei como líder da equipe e também participei do desenvolvimento. Organizei as responsabilidades e acompanhei as entregas usando um fluxo Kanban. O principal desafio foi coordenar o trabalho enquanto o grupo aprofundava seus conhecimentos nas tecnologias do projeto.

**Tecnologias:** `C#` `Unity` `Git` `GitHub`

➡️ [Repositório](https://github.com/2026-1-NCC1/Projeto5) · ✅ Concluído
