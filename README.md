## 🚀 Projetos em destaque

### 📚 Studie and Grow — caderno de estudos automatizado

Pipeline que sincroniza as anotações da minha base no Notion via API, converte o conteúdo para Markdown, gera o site com VitePress e publica no GitHub Pages. Tudo roda por um workflow do GitHub Actions, no agendamento diário ou sob demanda.

Foi onde aprendi na prática o que mais me interessa hoje: integrar serviços, automatizar processos e colocar algo no ar de ponta a ponta.

**Tecnologias:** `Node.js` `Notion API` `VitePress` `GitHub Actions` `GitHub Pages`

➡️ [Repositório](https://github.com/nicolasccampos/studie-and-grow) · [Site publicado](https://nicolasccampos.github.io/studie-and-grow/) · 🔄 Em evolução
